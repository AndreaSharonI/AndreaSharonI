### 🤖 [ASK-ME — Offline Smart Learning Assistant](https://github.com/AndreaSharonI/ASK-ME)

An educational software prototype designed to turn study passages into student-friendly learning material.

- 📝 Generates short, easy-to-understand summaries.
- ❓ Creates multiple-choice quiz questions from a passage.
- 🧠 Uses the `google/flan-t5-small` model through Hugging Face Transformers.
- 💻 Current version: Windows software prototype.
